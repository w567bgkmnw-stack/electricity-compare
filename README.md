# השוואת ספקי חשמל לפי הצריכה שלי

דף HTML יחיד שמשווה בין כל מסלולי ספקי החשמל הפרטיים בישראל, לפי נתוני הצריכה השעתיים שלכם מהמונה החכם.

## שימוש
1. מורידים מהאזור האישי בחברת החשמל את קובץ הצריכה (`meter_LP_….csv`):
   מצב צריכה עדכני ← "שליחת קובץ אקסל עם נתוני צריכה מהשנתיים האחרונות".
2. פותחים את `electricity-compare.html` בדפדפן וגוררים אליו את הקובץ.
3. בוחרים את המסלול הנוכחי (ברירת מחדל: חברת החשמל ללא הנחה) ומקבלים דירוג של כל המסלולים לפי חיסכון או עלות עודפת בשנה.

## איך זה מחושב
- כל שעה נבדקת בנפרד: יום בשבוע, שעה, וחג (במסלולים שמחריגים חגים). רק שעה שנמצאת בתוך חלון המסלול מקבלת את אחוז ההנחה שלו.
- ההנחה חלה על רכיב הצריכה בלבד. התשלומים הקבועים זהים אצל כל הספקים ואינם נכללים.
- הסכום מוכפל לשנה לפי מספר ימי הנתונים. אפשר לחשב רק מתאריך מסוים.

## מסלולים עדכניים
בכל פתיחה הדף מוריד את רשימת המסלולים מ[השוואת Supermarker](https://www.supermarker.themarker.com/bills/electricity), ישירות או דרך שירותי CORS ציבוריים (AllOrigins, CodeTabs, cors.lol). אם ההורדה נכשלת, משמשת רשימה מובנית, ואפשר גם לטעון דף השוואה שנשמר מהדפדפן.

## פרטיות ואבטחה
- נתוני הצריכה נקראים ומחושבים רק בדפדפן. הם לא נשלחים לשום מקום ולא נשמרים.
- מדיניות Content-Security-Policy מתירה רק את כתובות הורדת המסלולים וחוסמת כל כתובת אחרת. הסקריפט היחיד מאושר באמצעות hash.
- הדף שמורד מפוענח כנתונים בלבד (DOMParser): שום קוד ממנו לא רץ, וכל ערך נבדק (טווח אחוזים, שעות, ימים) לפני שימוש.
- `.gitignore` חוסם העלאה של קובצי צריכה (`*.csv`, `meter_LP_*`).

## הסתייגות
המידע על המסלולים לקוח מאתר השוואה ועשוי להשתנות. לפני מעבר ספק יש לאמת את התנאים מול הספק.
